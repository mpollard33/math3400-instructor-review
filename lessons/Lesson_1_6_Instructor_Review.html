Instructor content · page 1. Explanatory wording is tutor-added throughout.

y = x⁴ → dy/dx = 4x³
y = ∫4x³ dx = x⁴ + C

Differentiation forgets the constant. Integration recovers a family. What if y is defined implicitly?

F(x,y) = C
dF(x,y(x))/dx = ∂F/∂x + (∂F/∂y)(dy/dx) = 0

Along a solution, y depends on x. The chain rule contributes dy/dx.

M = ∂F/∂xCoefficient of dx
N = ∂F/∂yCoefficient of dy
M + N dy/dx = 0
M dx + N dy = 0

An equation is exact when both coefficients come from the partial derivatives of one function F. “Potential function” is the tutor's name for F.

Instructor content · page 1

F(x,y) = y² + 3x²eʸ
∂F/∂x = 6xeʸ
∂F/∂y = 2y + 3x²eʸ
(6xeʸ) dx + (2y + 3x²eʸ) dy = 0

Hold y fixed for the x partial derivative and x fixed for the y partial derivative.

Tutor clarification
The notes use y² + 3x²eʸ = 0. Over the reals, this level contains only (0,0), since both terms are nonnegative. The formal differentiation is valid, but this zero level is not a solution graph over an interval. F = C gives the general level family.

The notes later use F = 0 with the arbitrary constant absorbed into F. We retain their F₀ + C = 0 convention and identify each constant renaming.

Instructor theorem · page 1

If M and N are continuous and have continuous first partial derivatives on a rectangle R, the equation is exact on R if and only if:

∂M/∂y = ∂N/∂x
at every point of R

Necessity comes from equality of continuous mixed partial derivatives of F. The rectangle theorem also establishes sufficiency.

Tutor-added memory cue
Cross-check, then reconstruct. Differentiate the dx coefficient in y and the dy coefficient in x.

Tutor qualification: equality at one point or along one line isn't enough. On a region with a hole, equality alone need not produce a global potential.

Instructor Q1(a) · page 2

(12x³y³ + 2x) dx + 9x⁴y² dy = 0

First-order nonlinear equation. Test the exact pair.

Current action: compute ∂M/∂y and ∂N/∂x.
Reveal the instructor result
∂M/∂y = 36x³y² = ∂N/∂x

Exact. Polynomial coefficients and their partials are continuous on every rectangle.

Tutor-added check: F₀ = 3x⁴y³ + x² has these two partial derivatives.

Instructor Q1(b) · page 2

3eˣy² dx + 4eˣy dy = 0
Current action: test exactness as written.
Reveal the instructor result and correction
∂M/∂y = 6eˣy
∂N/∂x = 4eˣy

Not exact. Agreement on y = 0 isn't agreement throughout a rectangle.

Tutor-added trap: not exact doesn't mean unsolvable. Another method may work.

Instructor Q1(c) · page 2

−2x³ cos(2y)y′ = 3x² sin(2y)

Move terms to one side and multiply the entire equation by −1:

3x² sin(2y) + 2x³ cos(2y)y′ = 0
3x² sin(2y) dx + 2x³ cos(2y) dy = 0
Current action: test the cross partials. Include the chain-rule factor 2.
Reveal the instructor result
∂M/∂y = 6x² cos(2y) = ∂N/∂x

Exact. No division by x or cos(2y) was needed.

Tutor-added check: F₀ = x³ sin(2y) differentiates to M and N.

Instructor method · page 2; scaffold added by tutor

∂F/∂x = M
F = ∫M(x,y) dx + h(y)

Integrate in x while holding y fixed. Why not just +C?

∂(yeˣ)/∂x = yeˣ
∂(yeˣ + y⁴)/∂x = yeˣ
∂(yeˣ + h(y))/∂x = yeˣ

Every function of y disappears under differentiation in x. A numerical constant alone would discard terms we may need.

Memory cue
Integrate x, leave a function of y. Differentiate y, match N.

Differentiate F in y, match ∂F/∂y to N and solve for h′(y). Then integrate h′(y).

Reverse route, added by tutor

You may instead integrate N in y, leaving g(x), then match ∂F/∂x to M. The instructor examples take the first route.

Instructor worked example · page 2; exactness check added by tutor

yeˣ dx + (eˣ + 4y³) dy = 0

First-order nonlinear exact equation.

M = yeˣ, N = eˣ + 4y³
∂M/∂y = eˣ = ∂N/∂x
F = ∫yeˣ dx = yeˣ + h(y)

All coefficients and first partials are continuous everywhere. During integration, y is a constant multiplier.

Instructor worked example · page 2

∂F/∂y = eˣ + h′(y)
eˣ + h′(y) = eˣ + 4y³
h′(y) = 4y³
h(y) = y⁴ + C
yeˣ + y⁴ + C = 0

Subtract matching eˣ terms, then integrate in y. Equivalently yeˣ + y⁴ = K, where K = −C. No initial condition is supplied.

Tutor-added verification and restrictions

F₀ = yeˣ + y⁴
∂F₀/∂x = yeˣ = M
∂F₀/∂y = eˣ + 4y³ = N
dF₀/dx = yeˣ + (eˣ + 4y³)y′ = 0

Where N ≠ 0, the implicit relation defines a local differentiable y(x). At N = 0, y³ = −eˣ/4 and M = yeˣ ≠ 0, so no finite y′ can satisfy the ODE there.

Use a connected branch avoiding those points. No unique initial interval can be selected without an initial point. The constant solution y = 0 occurs when C = 0 and is valid for all real x.

Instructor worked example · pages 2–3

(2y³x + 1/x) dx + 3x²y² dy = 0
x > 0

Goal: give the solution explicitly. First-order nonlinear exact equation.

∂M/∂y = 6xy² = ∂N/∂x
F = ∫(2y³x + 1/x) dx
F = x²y³ + ln(x) + h(y)

The general antiderivative is ln|x|. The source specifies x > 0, so ln(x) is correct.

Instructor worked example · page 3

∂F/∂y = 3x²y² + h′(y) = 3x²y²
h′(y) = 0, so h(y) = C
x²y³ + ln(x) + C = 0
x²y³ = K − ln(x), with K = −C
y(x) = ∛[(K − ln(x))/x²]

The notes reuse C after changing its sign. K explicitly labels that equivalent arbitrary constant here. A real cube root has one real value, without a ± choice.

Tutor-added restriction and verification

Differentiate x²y³ + ln(x) = K:
2xy³ + 3x²y²y′ + 1/x = 0

This recovers the equation wherever the function is differentiable. At x = eᴷ the formula gives y = 0. The ODE would require 1/x = 0, which is impossible.

I = (0,eᴷ) or (eᴷ,∞)

These are the maximal connected intervals for classical y(x) solutions. If an initial point is supplied, choose its interval. The source gives none.

Common trap
A real-valued cube root need not have a finite derivative. Exclude x = eᴷ from a classical solution interval.

Instructor IVP · page 3; exactness calculation added by tutor

(5x⁴ + y cos(xy))
+ (x cos(xy) − sin(y))y′ = 0
y(1) = 0
M = 5x⁴ + y cos(xy)
N = x cos(xy) − sin(y)
∂M/∂y = cos(xy) − xy sin(xy)
∂N/∂x = cos(xy) − xy sin(xy)

First-order nonlinear exact equation. Product and chain rules give the same result. Coefficients and first partials are continuous on every rectangle.

Instructor IVP · page 3

F = ∫[5x⁴ + y cos(xy)] dx
F = x⁵ + sin(xy) + h(y)
∂F/∂y = x cos(xy) + h′(y)
x cos(xy) + h′(y) = x cos(xy) − sin(y)
h′(y) = −sin(y)
h(y) = cos(y) + C
x⁵ + sin(xy) + cos(y) + C = 0

Since ∂sin(xy)/∂x = y cos(xy), this antiderivative is valid even at y = 0. No division by y is necessary.

Instructor IVP · page 3; verification added by tutor

At (1,0): 1 + 0 + 1 + C = 0
C = −2
x⁵ + sin(xy) + cos(y) − 2 = 0
Differentiate:
5x⁴ + cos(xy)(y + xy′) − sin(y)y′ = 0
(5x⁴ + y cos(xy)) + (x cos(xy) − sin(y))y′ = 0

The initial point gives 1 + 0 + 1 − 2 = 0. Both ODE and initial condition are verified.

Tutor-added mathematical qualification

N(1,0) = 1
y′ = −[5x⁴ + y cos(xy)]/[x cos(xy) − sin(y)]
y′(1) = −5

Near (1,0), N remains nonzero. The slope function and its y partial derivative are continuous there, giving a unique local solution.

Connected interval: I = (1 − ε,1 + ε) for some sufficiently small ε > 0 whose solution branch stays in N ≠ 0. This doesn't claim that every ε works.

The source supplies no maximal endpoints and this studio doesn't calculate them. Continue the branch through (1,0) while it remains a differentiable solution. The nonzero-denominator argument cannot simply be extended through N = 0.

Exactness everywhere doesn't guarantee one differentiable y(x) graph for every real x.

Tutor-added application, not instructor content

For an ideal undamped, unforced mass-spring system, x is displacement in metres, v velocity in metres per second, m > 0 mass in kilograms and k > 0 stiffness in newtons per metre.

E(x,v) = ½kx² + ½mv²
dE = kx dx + mv dv = 0
∂(kx)/∂v = 0 = ∂(mv)/∂x

The exact differential expresses constant mechanical energy. Each term in E has units of joules.

dx/dt = v, m dv/dt = −kx
dE/dt = kxv + mv(−kx/m) = 0

At v = 0, a velocity-versus-displacement graph can have a vertical tangent while motion in time remains smooth. An implicit curve and a differentiable graph are different objects.

Tutor-added practice

(2xy + cos x) dx + (x² + 2y) dy = 0
y(0) = 1
Current action: test exactness and integrate M, keeping h(y).
Reveal this step
∂M/∂y = 2x = ∂N/∂x
F = ∫(2xy + cos x) dx
F = x²y + sin x + h(y)

Hold y fixed during integration in x.

Tutor-added practice, continued

(2xy + cos x) dx + (x² + 2y) dy = 0
y(0) = 1
Current action: determine h, apply the initial condition and verify.
Reveal solution and verification
∂F/∂y = x² + h′(y) = x² + 2y
h′(y) = 2y, h(y) = y² + C
x²y + sin x + y² + C = 0
At (0,1): C = −1
x²y + sin x + y² − 1 = 0

Differentiation gives 2xy + cos x + (x² + 2y)y′ = 0. Substitution verifies (0,1). Since N(0,1) = 2, a unique local branch exists on some connected neighborhood of x = 0. Maximal endpoints aren't determined here.

Tutor-added retrieval and correction

For M = 2xy and N = x² + 3y², a student writes F = x²y + C. What is the first consequential error?
Reveal answer and correction

The integration needs h(y), not only C. Matching ∂F/∂y = x² + h′(y) to N gives h′(y) = 3y² and h(y) = y³ + C.

x²y + y³ + C = 0

Both partial derivatives now match.

Tutor-added retrieval and correction

A student tests ∂M/∂x = ∂N/∂y. What should be tested, and where?
Reveal answer and correction

Test ∂M/∂y = ∂N/∂x at every point of a rectangle where M, N and their first partial derivatives are continuous. Cross-check, then reconstruct.

Agreement at one point or on a line isn't enough.

Tutor-added retrieval and correction

For y = ∛[(K − ln x)/x²], is x > 0 the complete restriction for a classical solution?
Reveal answer and correction

No. Exclude x = eᴷ, where y = 0 and the ODE would require 1/x = 0. Use (0,eᴷ) or (eᴷ,∞), selecting the interval containing any initial point.

The expression must be differentiable and satisfy the equation throughout its interval.

Cross-check, then reconstruct

  1. Arrange M dx + N dy = 0 without unnecessary division.
  2. Check continuity and ∂M/∂y = ∂N/∂x on a suitable rectangle.
  3. Integrate M in x, retaining h(y).
  4. Differentiate in y and match N.
  5. Integrate h′(y), assemble F and apply initial data.
  6. Verify the partial derivatives, initial point and interval.
