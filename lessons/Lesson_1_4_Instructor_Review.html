Numbered lesson roadmap

Direct integration is the bridge

First-order means the highest derivative is y′. When y′ = f(x), the right side depends only on x. Integrate with respect to x.

Example 0: dy/dx = ex/3
Reveal the worked example
  1. Write dy = ex/3 dx.
  2. Integrate: ∫ dy = ∫ ex/3 dx.
  3. y(x) = 3ex/3 + C. The factor 3 cancels the inner derivative 1/3.
  4. Verify: y′ = 3(1/3)ex/3 = ex/3. Valid on (−∞, ∞).
Memory cue · tutor-added
Undo the derivative, then differentiate to check.

Checkpoint: Why is ex/3 + C missing a factor?

Reveal checkpoint correction

Its derivative is (1/3)ex/3. Multiply the antiderivative by 3.

Recognize separation

Dr. Casey’s form is y′ = g(x)/f(y). After legal rearrangement:

f(y) dy = g(x) dx

The left side has y and dy. The right side has x and dx. The chain rule justifies integrating f(y(x))y′(x) with respect to x as ∫ f(y) dy.

Memory cue · tutor-added
Separate → integrate → apply data → check. Before division, check its zeros.

Try: Is y′ = x²(y² + 4) separable?

Reveal answer

Yes. dy/(y² + 4) = x² dx. The denominator y² + 4 is never zero for real y.

Separate and integrate the IVP

dy/dx = −6xy,   y(0) = 7

First-order, linear and separable: the right side is (−6x)y. Use separation, as in the notes.

Reveal the equation walkthrough
  1. Check y = 0 in the original equation: 0 = −6x·0. It is a solution, but it cannot satisfy y(0) = 7.
  2. For y ≠ 0, divide by y: (1/y) dy = −6x dx.
  3. Integrate both sides: ln|y| = −3x² + C. The difference between two integration constants is one arbitrary constant.
  4. Exponentiate: |y| = e−3x²+C = eCe−3x².
  5. Allow the sign of y in a renamed coefficient: y = Ce−3x². Here C is a new real constant. C = 0 restores the separately verified zero solution.
  6. Apply y(0) = 7: 7 = Ce⁰, so C = 7 and y(x) = 7e−3x².
  7. Verify: y′ = −42xe−3x² = −6xy and y(0) = 7. Connected interval: (−∞, ∞).
Memory cue · reused teaching rule
C in the exponent comes out as a coefficient: eF+C = eCeF. It does not become “eF + C.”

Checkpoint: The blue margin note also lists y(0) = −8. How would that change the solution?

Reveal answer

It selects C = −8, so y = −8e−3x². The printed y(0) = 7 remains the main IVP; the margin value is treated as an alternate condition.

Practice the separation step

Write one legal separated equation before integrating.

dy/dx = (x + 1)/(y² + 4)
Show a hint

Multiply both sides by y² + 4, then attach dx to the x side.

Reveal worked practice
  1. (y² + 4) dy = (x + 1) dx.
  2. Integrate: y³/3 + 4y = x²/2 + x + C.
  3. This implicit relation is sufficient. Differentiating gives (y² + 4)y′ = x + 1.
  4. No real zero of y² + 4 was excluded. The left side is strictly increasing from −∞ to ∞, so each C defines one real y for every real x.
Trap
Do not move dy to the side containing x while leaving a function of y there.

Explicit or implicit?

FormMeaning
Explicit: y = y(x)y is isolated.
Implicit: F(x,y) = 0x and y remain in a relation.
dy/dx = xe−y²/y,   y ≠ 0

First-order, nonlinear and separable. Multiply by yey².

Reveal the worked example
  1. yey² dy = x dx.
  2. Use u = y², du = 2y dy. Then ∫ yey² dy = (1/2)∫ eᵘ du.
  3. (1/2)ey² = (1/2)x² + C. This is the implicit solution shown in the notes.
  4. After renaming 2C as C: ey² = x² + C. Differentiation gives 2yey²y′ = 2x, hence the original equation where y ≠ 0.
  5. Optional explicit branches: y = ±√ln(x² + C). Choose one sign on a connected interval where x² + C > 1. Equality would give y = 0, where the original equation is undefined.

Checkpoint: Is (1/2)ey² − (1/2)x² − C = 0 explicit?

Reveal answer

No. y is not isolated. An implicit solution is still a valid solution description on an appropriate branch.

The initial value chooses the branch

dy/dx = x/(x²y + y),   y(0) = −2

First-order, nonlinear and separable. Factor the denominator before moving anything.

Reveal the full IVP walkthrough
  1. x²y + y = (x² + 1)y. The original equation requires y ≠ 0.
  2. y dy = x/(x² + 1) dx.
  3. With u = x² + 1 and du = 2x dx: y²/2 = (1/2)ln|x² + 1| + C.
  4. Multiply by 2 and rename the constant: y² = ln(x² + 1) + C. Since x² + 1 > 0, the absolute value is unnecessary.
  5. Apply (0, −2): 4 = ln 1 + C, so C = 4.
  6. The relation gives y = ±√[ln(x² + 1) + 4]. The negative initial value selects y(x) = −√[ln(x² + 1) + 4].
  7. Since ln(x² + 1) + 4 ≥ 4, y never reaches 0. Interval: (−∞, ∞). Differentiating y² = ln(x² + 1) + 4 gives 2yy′ = 2x/(x² + 1), verifying the equation.
Memory cue · tutor-added
Two algebraic signs, one initial-value branch.

Checkpoint: Why can’t the final IVP answer keep ±?

Reveal correction

The plus branch has y(0) = 2. Only the minus branch satisfies the stated condition.

Division can lose a solution

dy/dx = 6x(y − 1)2/3

The notes call a solution absent from the displayed general family a singular solution. Test excluded values in the original equation.

Reveal family and missing solution
  1. Before dividing by (y − 1)2/3, record y = 1 as a separate candidate.
  2. For y ≠ 1: (y − 1)−2/3 dy = 6x dx.
  3. Integrate: 3(y − 1)1/3 = 3x² + C.
  4. Divide by 3 and rename C: (y − 1)1/3 = x² + C. Thus y = 1 + (x² + C)³.
  5. Verify the family: y′ = 6x(x² + C)² and (y − 1)2/3 = (x² + C)². These polynomials satisfy the equation for all real x, including points where the original division failed.
  6. Verify y = 1: y′ = 0 and 6x(1 − 1)2/3 = 0. No fixed C makes x² + C vanish throughout an open interval. Thus y = 1 is missing from that family.
Memory cue · tutor-added
Divide? Record the zeros. Then substitute them back.

Checkpoint: Is every excluded value a solution?

Reveal correction

No. It is a candidate. For example, y = 0 is invalid for y′ = xe−y²/y because the original right side is undefined there.

Existence and uniqueness are separate

y′ = f(x,y),   y(a) = b
  1. ExistenceIf f is continuous on a rectangle containing (a,b) in its interior, a solution exists on some open interval containing a.
  2. UniquenessIf Dyf = ∂f/∂y is also continuous in a neighborhood of that point, the local solution is unique.
Memory cue · tutor-added
f: a path exists. ∂f/∂y: one path is guaranteed.

These are sufficient local conditions. A failed test alone proves neither “no solution” nor “multiple solutions.” Continuity at just one point is not the full neighborhood condition.

Reviewer note on wording

The notes use Dyf in the theorem and ∂f/∂y in the worked example. Both are retained. The phrase “open interval around (a,b)” on page 3 is expressed here as a neighborhood/rectangle in the xy-plane. The conclusion is local, not necessarily global.

A failed test, then actual nonuniqueness

y′ = ∛y,   y(0) = 0
Reveal theorem analysis
  1. f(x,y) = ∛y is continuous everywhere. Existence is guaranteed.
  2. ∂f/∂y = 1/(3y2/3) for y ≠ 0. It is undefined at y = 0. The theorem does not guarantee uniqueness.
  3. Separate positive solutions: y−1/3 dy = dx gives (3/2)y2/3 = x + C. With C = 0, y = (2x/3)3/2 for x ≥ 0.
  4. Compare two solutions on all real x: y₁(x) = 0; y₂(x) = 0 for x ≤ 0 and (2x/3)3/2 for x > 0. Both satisfy y(0) = 0.
  5. For x > 0, y₂′ = √(2x/3) = ∛y₂. At x = 0 its derivative is 0 from both sides. These two different solutions establish nonuniqueness.
Reveal the slope-field comparison

Fixed axes. Horizontal segments at y = 0 allow both staying at zero and departing smoothly.

Blue solid: y₁ = 0.

Correction to the inference
The handwritten “not unique” conclusion is correct for this example. The two actual solutions justify it; failure of the derivative condition alone would not.

Unique locally does not mean forever

y′ = 2x²y²,   y(−1) = 1

Which two functions need a continuity check near (−1,1)?

Reveal theorem answer

f = 2x²y² and ∂f/∂y = 4x²y are polynomials. Both are continuous everywhere. A unique local solution is guaranteed.

Reveal added interval check
  1. For y ≠ 0: y−2 dy = 2x² dx, so −1/y = (2/3)x³ + C.
  2. At (−1,1): −1 = −2/3 + C, hence C = −1/3.
  3. y = 3/(1 − 2x³). Its maximal connected interval containing −1 is (−∞, ∛(1/2)).
  4. Check: y′ = 18x²/(1 − 2x³)² = 2x²y². The solution blows up at the finite right endpoint despite the polynomial right side.

The notes use this for the theorem test. The explicit solution and interval are tutor-added clarification.

Keep the original equation in view

y(dy/dx) = x − 1 at (1,0)

Solving for y′ gives f(x,y) = (x − 1)/y. This form is undefined when y = 0.

Reveal conclusion and correction

The standard theorem does not guarantee a solution at (1,0), as the notes state. That does not mean the original equation has no solutions.

In fact y = x − 1 gives yy′ = (x − 1)·1 = x − 1. Also y = 1 − x gives yy′ = (1 − x)(−1) = x − 1. Both pass through (1,0) and satisfy the original implicit equation for all real x.

The divided equation is not equivalent at y = 0. These curves solve the original equation, not an undefined explicit right side at that point.

Trap
“Not guaranteed” and “impossible” are different claims.

Find the forbidden line

y′ = ln|x + 2y|,   y₀ = 5

For which x₀ does the theorem fail to guarantee existence at (x₀,5)?

Show a hint

ln|u| is defined for u ≠ 0. Substitute y₀ before solving for the forbidden value.

Reveal answer and neighborhood reasoning

x₀ + 2(5) = 0 gives x₀ = −10. At (−10,5), the right side is undefined.

At every point away from x + 2y = 0, choose a small rectangle that avoids the line. Both ln|x + 2y| and ∂f/∂y = 2/(x + 2y) are continuous there. A unique local solution is guaranteed.

Here the original explicit equation itself is undefined at the forbidden point. This is stronger evidence than merely failing a sufficient continuity test.

Step 1 of 4

Solve the bunny model

P′ = 0.001P²,   P(0) = 5

First-order, nonlinear and separable. t = 0 means today. The notes do not name the time unit, so retain “time units.”

Reveal the instructor-sequence walkthrough
  1. P = 0 is an equilibrium, but not the solution with P(0) = 5. For positive P, write 1000P−2 dP = dt.
  2. Integrate: −1000/P = t + C.
  3. Apply the initial value: −1000/5 = 0 + C, so C = −200.
  4. −1000/P = t − 200. Isolate P: P(t) = 1000/(200 − t).
  5. Verify P(0) = 5 and P′ = 1000/(200 − t)² = 0.001P².
  6. Mathematical interval containing 0: (−∞, 200). Forward population-model interval: 0 ≤ t < 200. The model predicts unbounded growth as t approaches 200 from below.
Interpretation
Blow-up is a limitation of this unrestricted model. It is not evidence that a real population becomes infinite.

Checkpoint: Is 0.001 an integration constant?

Reveal answer

No. It is the given model parameter. The initial value determines the integration constant C.

A measured rate determines k

P′ is proportional to √P. At t₀, P = 100 flies and P′ = 20 flies/month. Find the population one year later.

First-order, nonlinear and separable: P′ = k√P. Reset elapsed time so t = 0 at the observation, matching the handwritten solution.

Reveal parameter determination
  1. Insert the population and instantaneous rate into the law: 20 = k√100 = 10k.
  2. k = 2, with units √flies/month. Thus P′ = 2√P.
  3. “20 per month” is P′(0), not P(0), and not a constant rate for all later months.
Memory cue · tutor-added
A snapshot gives the amount. A rate measurement calibrates the law.

Checkpoint: What changes if the original time coordinate t₀ is retained?

Reveal answer

Use elapsed time t − t₀. The one-year prediction is at t = t₀ + 12 months.

Solve and interpret the fly model

P′ = 2√P,   P(0) = 100
Reveal solution and one-year prediction
  1. For P > 0: P−1/2 dP = 2 dt.
  2. Integrate: 2√P = 2t + C.
  3. At t = 0, P = 100: 20 = C, hence √P = t + 10.
  4. Square: P(t) = (t + 10)², retaining t + 10 ≥ 0. At t = 12 months, P = 22² = 484 flies.
  5. Verify for t > −10: P′ = 2(t + 10) = 2√P and P(0) = 100. The positive branch has interval (−10, ∞); the forward model uses t ≥ 0.
  6. Do not extend the squared formula to t < −10: then 2√P = 2|t + 10|, while P′ = 2(t + 10) is negative. A valid continuation sets P = 0 for t ≤ −10 and P = (t + 10)² for t > −10. It solves the equation on all real t.
Trap
Squaring can conceal a sign restriction. Keep √P = t + 10 beside the squared formula.

Reveal bacteria example from the recovered plan

Assume P′ = kP, P(0) = 210 and P(12) = 300. The plan does not specify the time unit.

  1. dP/P = k dt gives ln P = kt + C for P > 0, so P = Cekt after renaming the coefficient.
  2. P(0) = 210 gives C = 210. Then 300 = 210e12k, so k = ln(10/7)/12 per time unit.
  3. P(t) = 210(10/7)t/12. This is positive and solves P′ = kP for all real t. Forward interpretation uses t ≥ 0.
Reveal historical world-population modeling example

Illustrative inputs from the recovered plan: P(1999) = 6 billion and P′(1999) = 0.070 billion/year. These are supplied modeling data, not current demographic claims.

Under the assumed law P′ = kP, k = 0.070/6 = 7/600 per year. Therefore P(t) = 6e(7/600)(t−1999) billion. Substitution verifies both inputs. The exponential formula is defined for all real t; the constant-rate-per-person assumption limits its practical use.

Engineering connection: cooling a component

A heated component has temperature T(t). Its derivative T′(t) tells how fast the temperature changes. This reuses the same state-versus-rate distinction as P and P′.

Assume uniform component temperature, constant ambient temperature Tₐ = 20°C and Newton cooling T′ = −k(T − Tₐ), with k = 0.2 min⁻¹ and T(0) = 80°C.

First-order, linear and separable. The negative sign makes a hotter component cool toward the surroundings.

Reveal engineering walkthrough
  1. Check the equilibrium T = 20°C. It solves the law but not T(0) = 80°C.
  2. dT/(T − 20) = −0.2 dt, so ln|T − 20| = −0.2t + C.
  3. T − 20 = Ce−0.2t. Apply T(0) = 80: C = 60°C.
  4. T(t) = 20 + 60e−0.2t °C, with t in minutes. T′ = −12e−0.2t °C/min verifies the equation.
  5. The mathematical solution is defined on (−∞, ∞). The forward experiment uses t ≥ 0. A nonuniform temperature or changing surroundings would require a different model.

Tutor-added engineering application. This is not an example or a modeling assumption quoted from Dr. Casey’s notes.

Guided synthesis: model first

A culture grows at a rate proportional to the square root of its population. Initially there are 64 organisms and the rate is 12 organisms/hour. Predict the population after 4 hours.

One decision: write the differential equation and the two measured facts.

Show a hint

Distinguish an amount from its derivative. “Square root” acts on the amount.

Reveal setup and correction

P′ = k√P, P(0) = 64 and P′(0) = 12. It is separable because k√P depends only on P.

If you wrote P = k√P, the first error was replacing the growth rate with the amount. If you wrote P′ = 12 for all t, you made an instantaneous observation into a permanent law.

Guided synthesis: calibrate and solve

P′ = k√P,   P(0) = 64,   P′(0) = 12

Find k, then separate the calibrated equation.

Reveal solution steps
  1. 12 = k√64 = 8k, so k = 3/2 √organisms/hour.
  2. dP/√P = (3/2) dt, hence 2√P = (3/2)t + C.
  3. 16 = C. Therefore √P = (3/4)t + 8 and P = [(3/4)t + 8]².
  4. At 4 hours, P(4) = 11² = 121 organisms.
  5. Positive branch: t > −32/3 hours. Forward interpretation: t ≥ 0. For this branch P′ = (3/2)[(3/4)t + 8] = (3/2)√P. Initial amount and initial rate both check.
  6. The squared expression is invalid to the left of −32/3. As with the fly model, continuation by P = 0 before that time yields a differentiable solution on all real t.

Correction cue: ∫P−1/2 dP = 2√P. The exponent increases by 1, then you divide by the new exponent.

Exit check: constants and an IVP

Solve y′ = 2xy with y(0) = −3.
Reveal answer and correction

For nonzero y: dy/y = 2x dx, then ln|y| = x² + C. Thus y = Cex² after absorbing magnitude and sign into a new C. The initial condition gives y = −3ex².

It is valid on (−∞, ∞). Differentiation gives y′ = −6xex² = 2xy. The zero equilibrium cannot meet the initial condition.

Correction: exponentiating a sum produces a product, not ex² + C.

Reveal answer and correction

The relation is implicit. The selected explicit branch is y = −√(x² + 9), valid for all real x. The plus branch gives the wrong initial value.

Correction: ± describes two branches. It is not the final selection for this IVP.

Exit check: verify the lost solution

A calculation divided y′ = (y − 4)2/3 by (y − 4)2/3. What must be checked separately?
Reveal answer and correction

Check y = 4 in the original equation. Both sides are zero, so it is a solution.

Exit check: theorem versus conclusion

For y′ = ∛y with y(0) = 0, what does continuity of f guarantee? What does failure of the derivative test fail to guarantee?
Reveal answer and correction

Continuity of f near (0,0) guarantees local existence. The derivative test does not guarantee uniqueness. The zero and departing solutions from the worked example separately establish actual nonuniqueness.

Slope-field retrieval: all segments on y = 0 are horizontal because the entire right side ∛y is zero. Above y = 0, slopes are positive; below it, slopes are negative.

Exit check: interpret the data

A population obeys P′ = kP². At the observation time it has 10 individuals and grows at 2 individuals/day. Determine k and its units.
Reveal answer and correction

2 = k·10², so k = 0.02 (individual·day)−1.

Correction: the measurement gives a derivative, not a later population value. Doubling P would multiply the instantaneous rate by four for the same k.

Fresh correction check

If instead P′ = k√P, with P = 25 and P′ = 10 individuals/day, find k.

Reveal fresh answer
