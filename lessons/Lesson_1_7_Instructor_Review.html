Substitution methods

One lesson, two parts. Change the variable to reveal a simpler equation.

Source-checked against all eight pages of the supplied notes. Added explanations, practice and engineering examples are labeled. Navigation records no student progress.

Four substitution types

OrderDiagnostic featureSubstitution → simpler equation
Part A · 1Second order, no undifferentiated yv = y′ → first order in v
Part A · 2y′ depends only on y/xv = y/x → separable
Part B · 3y′ + P(x)y = Q(x)yⁿv = y¹⁻ⁿ → linear in v
Part B · 4A repeated expression, here x + y + 3v = x + y + 3 → separable

Prerequisites: product and chain rules, separation, integration and the first-order linear integrating factor ρ. “Homogeneous” here means dependence on y/x, not simply a zero forcing term in a linear equation.

Show the complete numbered roadmap

    1. Reduce the order

    A second-order equation with no undifferentiated y can be rewritten as an equation for its slope. The source starts with y″ = 2y′.

    Source correction. The printed definition says “if y′ is missing.” Its examples and v = y′ method require y to be missing. Missing y′ alone doesn't justify this method. This is the reducible case covered here, not an exhaustive definition of order reduction.

    Worked example: y″ = 2y′. Why should the new variable represent the slope?

    1. Recognize and define

      Reveal this step and explanation

      y itself is absent. Set v(x) = y′(x). The new dependent variable is v; x remains independent.

      v′(x) = y″(x)

      Differentiate v = y′ once with respect to x. No chain-rule factor is missing.

    2. Substitute and classify

      Reveal this step and explanation
      y″ = 2y′ → v′ = 2v

      This first-order equation is both separable and linear. The order drops because no y remains after the substitution.

    3. Solve for the slope

      Reveal this step and explanation
      dv/v = 2 dx
      ln|v| = 2x + C
      v = A e²ˣ

      Separation assumes v ≠ 0. Restoring v = 0 allows A = 0; signed A also includes negative slopes. The source writes ln(v); ln|v| is needed for both signs.

    4. Return to the original variable

      Reveal this step and explanation
      y′ = A e²ˣ
      y = (A/2)e²ˣ + B = C₁e²ˣ + C₂

      Define C₁ = A/2 explicitly. A second-order general solution carries two independent constants.

    5. Domain and verification

      Reveal this step and explanation
      y′ = 2C₁e²ˣ,   y″ = 4C₁e²ˣ = 2y′

      Every real C₁ and C₂ gives a solution on (−∞, ∞). C₁ = 0 gives the constant solutions lost if v = 0 is discarded.

      Memory cue, tutor-added: solve the slope, then integrate once more. Stopping at v is only half the return trip.

    2. Recover y after solving v

    Instructor “You try”: xy″ + y′ = 4x. Work each action before revealing its answer.

    1. Which variable is missing?

      Reveal this step and explanation

      y is absent. Put v = y′, so v′ = y″. Substitution gives xv′ + v = 4x. For x ≠ 0, divide by x:

      v′ + (1/x)v = 4

      The reduced equation is first-order linear.

    2. Build the integrating factor

      Reveal this step and explanation

      ρ = exp(∫1/x dx) = |x|. On a fixed positive or negative interval, the nonzero multiple ρ = x also works.

      xv′ + v = 4x → (xv)′ = 4x
      xv = 2x² + C₁

    3. Integrate the recovered derivative

      Reveal this step and explanation
      v = y′ = 2x + C₁/x
      y = x² + C₁ln|x| + C₂

      The notes switch the plus sign to minus in the last line. Both signs describe the same family only after renaming the arbitrary constant. Keeping the same C₁ across these steps requires the plus sign.

    4. Check the interval and the original equation

      Reveal this step and explanation
      y′ = 2x + C₁/x,   y″ = 2 − C₁/x²
      xy″ + y′ = 2x − C₁/x + 2x + C₁/x = 4x

      For C₁ ≠ 0 the maximal intervals are (−∞, 0) or (0, ∞). When C₁ = 0, y = x² + C₂ extends smoothly through x = 0 and solves the original, undivided equation on ℝ.

      Trap: a restriction introduced by division may be removable for a special solution. Check the original equation.

    3. A ratio becomes a variable

    The notes define a homogeneous first-order equation by y′ = F(y/x). Every occurrence of x and y on the right must combine into the ratio.

    Why isn't y′ simply v′ when v = y/x?

    1. Define and differentiate

      Reveal this step and explanation
      v = y/x,   y = xv
      y′ = (xv)′ = v + xv′

      x ≠ 0 for this coordinate change. Both factors x and v(x) vary, so the product rule contributes two terms.

      Memory cue, tutor-added: ratio → product → product rule.

    2. Substitute and separate

      Reveal this step and explanation
      v + xv′ = F(v)
      xv′ = F(v) − v
      dv/[F(v) − v] = dx/x

      The transformed equation is separable. Before dividing, solve F(v) − v = 0. Every admissible real root v = k gives the straight-line candidate y = kx.

    3. Recognize the two examples

      Reveal this step and explanation

      For y′ = cos(y/x) + (y/x)², F(v) = cos(v) + v² and xv′ = cos(v) + v² − v. The notes use this for recognition, not an elementary closed-form solution.

      For y′ = y/x + √(x/y), F(v) = v + v⁻¹ᐟ² on v > 0. Its v terms cancel after substitution, making it especially simple.

      Trap: separable doesn't guarantee an elementary antiderivative. An integral relation can still define a valid solution locally.

    4. Preserve the outside factor x

    Solve y′ = y/x + √(x/y).

    1. Domain, variable and derivative

      Reveal this step and explanation

      The original equation requires x ≠ 0, y ≠ 0 and x/y > 0. Set v = y/x > 0. Then y = xv and y′ = v + xv′.

    2. Substitute into the original equation

      Reveal this step and explanation
      v + xv′ = v + v⁻¹ᐟ²
      xv′ = v⁻¹ᐟ²

      The ratio substitution produces a separable equation. The right side is strictly positive, so no constant v solution was lost here.

    3. Separate and integrate

      Reveal this step and explanation
      v¹ᐟ² dv = dx/x
      (2/3)v³ᐟ² = ln|x| + C₀
      v³ᐟ² = (3/2)ln|x| + C = B(x)

      Multiplying the arbitrary constant by 3/2 is a legitimate renaming. Since v > 0, B(x) must be positive.

    4. Back-substitute correctly

      Reveal this step and explanation
      v = B(x)²ᐟ³
      y = xv = x[(3/2)ln|x| + C]²ᐟ³

      Source correction: Part A page 3 drops the leading x in the final line. That expression is v, not y. There is no ± branch here: v > 0, and the sign of y follows the sign of x.

    5. State the interval and verify

      Reveal this step and explanation

      Let a = e−2C/3. Maximal real intervals are (a, ∞) and (−∞, −a), with the same formula on either interval. Endpoints B = 0 would give y = 0, where the original equation is undefined.

      B′ = 3/(2x)
      y′ = B²ᐟ³ + B⁻¹ᐟ³
      y/x + √(x/y) = B²ᐟ³ + B⁻¹ᐟ³

      Trap: allowing B < 0 after taking a 2/3 power creates extraneous expressions that don't satisfy the original radical equation.

    5. Keep the implicit solution useful

    Show that 2xy y′ = 4x² + 3y² is homogeneous, then solve.

    1. Recognize and derive the substitution

      Reveal this step and explanation
      y′ = 2(x/y) + (3/2)(y/x)
      v = y/x,   y = xv,   y′ = v + xv′

      On x ≠ 0 and y ≠ 0, the right side is 2/v + 3v/2.

    2. Substitute, then separate

      Reveal this step and explanation
      v + xv′ = 2/v + 3v/2
      xv′ = (4 + v²)/(2v)
      [2v/(4 + v²)] dv = dx/x

      No real constant v solves 4 + v² = 0. v = 0 is excluded by the original equation for x ≠ 0.

    3. Integrate and return to y

      Reveal this step and explanation
      ln(4 + v²) = ln|x| + K
      4 + v² = A|x|,   A > 0
      4 + (y/x)² = Cx
      4x² + y² = Cx³

      On each fixed-sign interval, absorb the sign of x into C. The restriction Cx > 4 remains necessary for real nonzero y. Don't interpret C as unrestricted at each x.

    4. Branches and connected intervals

      Reveal this step and explanation
      y = ±√(Cx³ − 4x²)

      Each sign is fixed on a connected solution interval. If C > 0, use (4/C, ∞). If C < 0, use (−∞, 4/C). C = 0 gives no real solution on an open interval.

      At x = 0 the original equation forces y = 0, but this family has no real points in a punctured neighborhood of 0 for finite C. It supplies no smooth crossing there.

    5. Verify without expanding a square root

      Reveal this step and explanation
      8x + 2yy′ = 3Cx²
      2xyy′ = 3Cx³ − 8x²
      = 3(4x² + y²) − 8x² = 4x² + 3y²

      Implicit differentiation is the cleanest verification. This same family reappears in Part B using Bernoulli's method.

    6. Initial data select a branch

    Solve y′ = (x − y)/(x + y),   y(1) = 2.

    1. Set up and differentiate

      Reveal this step and explanation

      Near x = 1, use v = y/x, y = xv and y′ = v + xv′. The original restriction is x + y ≠ 0; the substitution additionally uses x ≠ 0.

      v + xv′ = (1 − v)/(1 + v)
      xv′ = (1 − 2v − v²)/(1 + v)

    2. Check the solutions division might lose

      Reveal this step and explanation

      Before dividing by 1 − 2v − v², solve it: v = −1 ± √2. The lines y = (−1 ± √2)x solve the ODE for x ≠ 0. Neither meets y(1) = 2. v = −1 is forbidden by x + y = 0.

    3. Separate with a second, calculus substitution

      Reveal this step and explanation
      ∫(1 + v)/(1 − 2v − v²) dv = ∫dx/x
      u = 1 − 2v − v²
      du = −2(1 + v)dv
      −(1/2)ln|u| = ln|x| + K

      This u-substitution evaluates the integral; v = y/x is the differential-equation substitution.

    4. Return and apply the initial condition

      Reveal this step and explanation
      1 − 2v − v² = C/x²
      x² − 2xy − y² = C
      1 − 4 − 4 = −7
      x² − 2xy − y² = −7

      The separated calculation initially has C ≠ 0. Restoring C = 0 recovers the straight lines checked earlier.

    5. Choose the branch and maximal interval

      Reveal this step and explanation
      (y + x)² = 2x² + 7
      y = −x + √(2x² + 7)

      The positive square-root branch gives y(1) = −1 + 3 = 2. The negative branch gives −4.

      The chosen solution extends to all ℝ. Although v = y/x fails at x = 0, the original equation doesn't: x + y = √(2x² + 7) > 0 everywhere.

    6. Verify the continuation

      Reveal this step and explanation

      Let s = √(2x² + 7). Then y′ = −1 + 2x/s and (x − y)/(x + y) = (2x − s)/s, the same expression. Both the ODE and initial value hold.

      Memory cue, tutor-added: the substitution's boundary isn't automatically the solution's boundary. Test the original equation before extending.

    7. A power becomes linear

    Bernoulli form: y′ + P(x)y = Q(x)yⁿ. Why does v = y¹⁻ⁿ work?

    1. Recognize the power and its exceptions

      Reveal this step and explanation

      P and Q depend only on x; n is constant. n = 0 is already linear. n = 1 gives y′ + (P − Q)y = 0, also linear. Use the nonlinear Bernoulli transformation for n ≠ 0, 1 on a real differentiable branch.

      Check y = 0 in the original equation before dividing by powers of y. It's a solution for many positive n cases, but isn't even defined for negative n.

    2. Define and differentiate explicitly

      Reveal this step and explanation
      v = y¹⁻ⁿ
      v′ = (1 − n)y⁻ⁿy′
      y⁻ⁿy′ = v′/(1 − n)

      The notes equivalently write y = v1/(1−n), giving y′ = [1/(1 − n)]vn/(1−n)v′. Inverting powers may require branches.

    3. Substitute and identify the simpler equation

      Reveal this step and explanation
      y⁻ⁿy′ + P(x)y¹⁻ⁿ = Q(x)
      v′/(1 − n) + P(x)v = Q(x)
      v′ + (1 − n)P(x)v = (1 − n)Q(x)

      This is first-order linear in v. The source's “linear in v′” label is imprecise: the whole equation is linear in v and its derivative.

      Memory cue, tutor-added: one minus n changes both coefficients, not just the power.

    4. Solve and return

      Reveal this step and explanation
      ρ = exp(∫(1 − n)P(x) dx)
      (ρv)′ = ρ(1 − n)Q(x)

      Integrate for v, then recover every admissible real y branch. Keep connected intervals where coefficients are defined and the inverse substitution remains valid. Substitute back to verify.

    8. A reciprocal cube root

    Solve y′ + (6/x)y = 3y⁴ᐟ³.

    1. Classify, define and differentiate

      Reveal this step and explanation

      Bernoulli with P(x) = 6/x, Q(x) = 3 and n = 4/3. For nonzero y set v = y⁻¹ᐟ³. Use the real cube root, which allows negative y.

      y = v⁻³,   y′ = −3v⁻⁴v′

    2. Substitute before simplifying

      Reveal this step and explanation
      −3v⁻⁴v′ + (6/x)v⁻³ = 3v⁻⁴
      v′ − (2/x)v = −1

      Division by −3v⁻⁴ produces the minus sign. The resulting equation is linear.

    3. Integrating factor and integration

      Reveal this step and explanation
      ρ = e−2ln|x| = x⁻²
      (x⁻²v)′ = −x⁻²
      x⁻²v = 1/x + C
      v = x + Cx²

      The antiderivative of −x⁻² is +x⁻¹.

    4. Recover y and restore the excluded solution

      Reveal this step and explanation
      y = (x + Cx²)⁻³

      Also y ≡ 0 solves the original equation wherever x ≠ 0. It wasn't represented by v = y⁻¹ᐟ³.

      For nonzero solutions, take any maximal connected component of ℝ minus {0, −1/C}, omitting −1/C when C = 0. For y ≡ 0, the intervals are (−∞, 0) and (0, ∞).

    5. Verify in one denominator

      Reveal this step and explanation

      Put w = x + Cx². Then y′ = −3(1 + 2Cx)w⁻⁴.

      y′ + (6/x)y
      = [−3(1 + 2Cx) + 6w/x]w⁻⁴
      = 3w⁻⁴ = 3y⁴ᐟ³

      Both signs of nonzero w are allowed because cube roots are real for both signs. w = 0 is a blow-up, not a branch crossing.

    9. One v, two possible y branches

    Solve y′ − [3/(2x)]y = 2xy⁻¹.

    1. Define v without losing the negative branch

      Reveal this step and explanation

      n = −1, so v = y². The original equation requires x ≠ 0 and y ≠ 0.

      v′ = 2yy′

      The notes use y = √v during the derivation. That represents only the positive branch; y = −√v must also be considered. Differentiating v = y² directly handles both.

    2. Substitute and solve the linear equation

      Reveal this step and explanation

      Multiply the original equation by 2y:

      2yy′ − (3/x)y² = 4x
      v′ − (3/x)v = 4x

      ρ = e−3ln|x| = |x|⁻³. On either fixed-sign interval we may choose its nonzero constant multiple x⁻³, as in the notes.

    3. Integrate and back-substitute

      Reveal this step and explanation
      (x⁻³v)′ = 4x⁻²
      x⁻³v = −4/x + C
      v = −4x² + Cx³
      y² + 4x² = Cx³

      This is exactly the implicit family from Part A's 2xyy′ = 4x² + 3y².

    4. Branches and restrictions

      Reveal this step and explanation
      y = ±√(Cx³ − 4x²)

      Require Cx > 4. C > 0 gives (4/C, ∞); C < 0 gives (−∞, 4/C). C = 0 gives no real solution. Choose one fixed sign per interval. y = 0 is forbidden, not an additional solution.

    5. Verify using v

      Reveal this step and explanation
      v′ − 3v/x
      = (3Cx² − 8x) − (3Cx² − 12x) = 4x

      Since v = y² and y ≠ 0, division by 2y returns the original equation on either branch.

      Trap: an even-power substitution merges signs; an initial condition is needed to choose one.

    10. Rename the expression that repeats

    The notes' general procedure is: set v = α(x,y), differentiate both sides and substitute to obtain an equation in x and v.

    Solve y′ = (x + y + 3)² using v = x + y + 3.

    1. Diagnostic and derivative relationship

      Reveal this step and explanation

      The expression x + y + 3 appears as one unit. Set v = x + y + 3. Since y depends on x:

      v′ = 1 + y′,   y′ = v′ − 1

      For a general differentiable α, the tutor-added chain-rule explanation is v′ = ∂α/∂x + (∂α/∂y)y′. A substitution helps only if the resulting equation is simpler and y can be recovered on the chosen branch.

    2. Substitute and solve the separable equation

      Reveal this step and explanation
      v′ − 1 = v²
      v′ = 1 + v²
      ∫dv/(1 + v²) = ∫dx
      arctan(v) = x + C

      1 + v² is positive for every real v, so division loses no real equilibrium solution.

    3. Return to y

      Reveal this step and explanation
      x + y + 3 = tan(x + C)
      y = tan(x + C) − x − 3

      The source labels this “Sub back for x,” but the actual operation replaces v with x + y + 3. x remains the independent variable.

    4. Intervals, branches and verification

      Reveal this step and explanation

      Take any interval (−π/2 − C + kπ, π/2 − C + kπ), where k is an integer. Do not cross a tangent pole. The principal arctan relation is local; shifting C by an integer multiple of π describes the same tangent family.

      y′ = sec²(x + C) − 1 = tan²(x + C)
      (x + y + 3)² = tan²(x + C)

      Memory cue, tutor-added: rename, differentiate, replace, return. The derivative of x contributes the easy-to-miss +1.

    11. Choose by structure

    These are the seven source classification problems in their printed order. Each reveal includes a reason and a tutor-added solution check. More than one method can be valid.

    For each equation, name a method and the feature that justifies it before revealing.

    1. 1 · x²y′ = xy + y²

      Reveal this step and explanation

      For x ≠ 0, y′ = y/x + (y/x)², so it is homogeneous. It is also Bernoulli with n = 2.

      v = y/x,   y′ = v + xv′
      xv′ = v²
      −1/v = ln|x| + C
      y = −x/(ln|x| + C)

      Restore y ≡ 0, lost when dividing by v². For nonzero solutions avoid x = 0 and ln|x| + C = 0. Substitution gives xv′ = v² again, verifying the family locally. y ≡ 0 extends through x = 0 in the original undivided equation.

    2. 2 · y″ = 1 + (y′)²

      Reveal this step and explanation

      Reducible because y is absent. The green source annotation also appears to list y″ as absent, but y″ is visibly present.

      v = y′,   v′ = y″
      v′ = 1 + v² → arctan(v) = x + C₁
      y′ = tan(x + C₁)
      y = −ln|cos(x + C₁)| + C₂

      Use any interval between adjacent zeros of cos(x + C₁). Check: y″ = sec²(x + C₁) = 1 + tan²(x + C₁). No real equilibrium v is lost.

    3. 3 · x³ + 4y − xy′ = 0

      Reveal this step and explanation

      Linear after rearrangement, not a substitution problem:

      y′ − 4y/x = x²
      ρ = x⁻⁴,   (x⁻⁴y)′ = x⁻²
      y = −x³ + Cx⁴

      The linear calculation uses x ≠ 0. This polynomial extends through 0 and verifies the original equation: x³ + 4(−x³ + Cx⁴) − x(−3x² + 4Cx³) = 0. No uniqueness through the singular point is asserted.

    4. 4 · 2sec²(2x − 5y) = 5sec²(2x − 5y)y′

      Reveal this step and explanation

      Exact after moving terms left: M = 2sec²(u), N = −5sec²(u), u = 2x − 5y.

      ∂M/∂y = ∂N/∂x = −20sec²(u)tan(u)
      d[tan(2x − 5y)] = 0

      The notes' displayed derivative omits a sec factor. The exactness conclusion is still correct. Since sec²(u) is nonzero wherever defined, direct cancellation is even shorter: y′ = 2/5, so y = 2x/5 + C.

      Along these lines u = −5C. Require cos(5C) ≠ 0; then the solution is valid for all real x. Cancelling does not make the forbidden lines valid.

    5. 5 · xy′ + 2y = 6x²√y

      Reveal this step and explanation

      For x ≠ 0, y′ + 2y/x = 6x y¹ᐟ². Bernoulli with n = 1/2. Let v = √y ≥ 0.

      y = v²,   y′ = 2vv′
      v′ + v/x = 3x
      (xv)′ = 3x² → v = x² + C/x

      For positive solutions, y = (x² + C/x)² with x² + C/x > 0. Also check y ≡ 0. Squaring a negative v introduces false solutions. The next stage works through branches and zero joins.

    6. 6 · 2xy² − x²y′ = y²

      Reveal this step and explanation

      Separable. Rearrange carefully:

      −x²y′ = (1 − 2x)y²
      y′ = [(2x − 1)/x²]y²
      dy/y² = (2/x − 1/x²)dx
      −1/y = 2ln|x| + 1/x + C

      Thus y = −1/[2ln|x| + 1/x + C], plus y ≡ 0. Use connected intervals avoiding x = 0 and zeros of the denominator. The notes change −x²y′ to +x²y′ without negating the other side. Their displayed sign is wrong; “separable” remains correct.

      Check: if D = 2ln|x| + 1/x + C, then y′ = D′/D² = [(2x − 1)/x²]y². The zero solution extends across x = 0 in the original equation.

    7. 7 · 2xy + x²y′ = y²

      Reveal this step and explanation

      For x ≠ 0, y′ = (y/x)² − 2(y/x). Homogeneous, and also Bernoulli with n = 2.

      v = y/x → xv′ = v(v − 3)
      dv/[v(v − 3)] = dx/x
      (1/3)ln|(v − 3)/v| = ln|x| + K
      v = 3/(1 − Cx³)
      y = 3x/(1 − Cx³)

      Restore v = 0 → y ≡ 0. v = 3 → y = 3x is already included when C = 0. Verification: y′ = (3 + 6Cx³)/(1 − Cx³)² makes 2xy + x²y′ = 9x²/(1 − Cx³)² = y².

      The explicit family extends through x = 0 in the original equation. Use maximal intervals avoiding a real pole 1 − Cx³ = 0, or all ℝ when C = 0.

    12. Squaring isn't a branch check

    Guided practice: xy′ + 2y = 6x²√y. Tutor-added initial condition: y(1) = 4.

    1. What substitution and derivative should you use?

      Reveal this step and explanation

      For x ≠ 0 the equation is Bernoulli with n = 1/2. On y > 0, let v = √y > 0; y = v² and y′ = 2vv′. The principal square root is nonnegative.

    2. Substitute into the original equation

      Reveal this step and explanation
      2xvv′ + 2v² = 6x²v
      v′ + v/x = 3x

      Divide by 2xv only after noting x ≠ 0 and v > 0. y ≡ 0 must be checked separately.

    3. Solve for v

      Reveal this step and explanation
      ρ = x on a fixed-sign interval
      (xv)′ = 3x²
      xv = x³ + C
      v = x² + C/x

      The convenient ρ = x is a nonzero multiple of exp(ln|x|) on each such interval.

    4. Apply the initial condition before squaring

      Reveal this step and explanation
      v(1) = √4 = 2
      2 = 1 + C → C = 1
      y = (x² + 1/x)²

      For x > 0, v > 0. The maximal interval containing x = 1 is (0, ∞); this solution blows up as x → 0⁺.

    5. Verify and diagnose the likely mistake

      Reveal this step and explanation

      Put w = x² + 1/x > 0. Then y′ = 2w(2x − 1/x²).

      xy′ + 2y = 2w[xw′ + w] = 6x²w = 6x²√y

      If w were negative, √(w²) would be |w|, not w. The squared expression would generally fail this check.

    6. What about y = 0 and joins?

      Reveal this step and explanation

      y ≡ 0 solves the original equation. The square-root right side is not locally Lipschitz in y at 0, so uniqueness there is not guaranteed.

      For example on x > 0, choose a > 0. Set y = 0 for 0 < x ≤ a, then y = (x² − a³/x)² for x ≥ a. Both y and y′ meet at 0 at x = a and the positive branch has √y = x² − a³/x. This is a valid delayed departure, not an extra arbitrary sign.

      This tutor-added edge case does not affect the IVP y(1) = 4, which remains strictly positive on its interval.

    13. Solve velocity, then position

    A mass moves horizontally with linear drag and no applied force. Assume constant mass m > 0 and drag coefficient b > 0, with drag force −bs′.

    m s″ + b s′ = 0,   s(0) = s₀,   s′(0) = V₀. How far does it coast?

    t is time [s], s(t) is displacement [m], s′ is velocity [m/s], s″ is acceleration [m/s²], m is mass [kg] and b has units [kg/s]. This model is an analogy added by the tutor, not an instructor example.

    1. Recognize, define and differentiate

      Reveal this step and explanation

      s is absent, so this is reducible. Define V(t) = s′(t), with V′(t) = s″(t). Put β = b/m, with units s⁻¹.

      V′ + βV = 0

      Every term has units m/s². βt is dimensionless.

    2. Solve the first-order equation

      Reveal this step and explanation
      dV/V = −β dt
      V = A e−βt
      V(0) = V₀ → A = V₀

      V₀ = 0 includes the stationary case, which separation would otherwise discard.

    3. Recover position and apply the other condition

      Reveal this step and explanation
      s′ = V₀e−βt
      s(t) = s₀ + (V₀/β)(1 − e−βt)

      V₀/β has units of length. Two initial data determine the two integration constants.

    4. Verify and interpret

      Reveal this step and explanation

      s′ = V₀e−βt and s″ = −βV₀e−βt, so ms″ + bs′ = (−mβ + b)V₀e−βt = 0. Both initial conditions hold.

      The mathematical solution is defined on ℝ; the physical experiment uses t ≥ 0. Net displacement tends to V₀/β = mV₀/b; total distance traveled is |mV₀/b|. There is no reversal in this model.

      Transfer question: If b doubles while m and V₀ stay fixed, the limiting travel distance halves. This follows from the formula, not from a claim that all drag laws are linear.
