y′ + x2y = sin(x)

Does the x2 make this equation nonlinear? Explain briefly.

Consider the question, then open the explanation when ready. All later stages are available with Next.

Show a hint

Compare the term x2y with P(x)y. Which symbol is being squared?

Reveal the explanation

No. The unknown y appears to the first power and its coefficient is the function P(x) = x2. The equation fits Casey’s linear form, with Q(x) = sin(x).

ρ(x) = e∫P(x) dx

Start with y′ + P(x)y = Q(x). Choose any one antiderivative F of P, then set ρ = eF. The exponential is nonzero wherever F is defined.

F′(x) = P(x)
ρ′(x) = eF(x)F′(x) = ρ(x)P(x)

This last identity is the reason for the choice. We want the multiplier’s derivative to supply exactly the coefficient of y.

Why no +C in the integrating factor?

Using F + K gives eKρ. This is a nonzero constant multiple of ρ and works just as well. We need only one multiplier. We still need an arbitrary constant when integrating the differential equation.

ρy′ + ρP(x)y = ρQ(x)

Multiply the entire equation by ρ(x), including its right side.

ρy′Multiplier × derivative of y
ρ′yDerivative of multiplier × y
Because ρ′ = ρP, the left side is ρy′ + ρ′y.
Common trap
Multiplying only the left side changes the equation. The right side must become ρQ.
d/dx [ρ(x)y] = ρ(x)Q(x)
Product rule: (ρy)′ = ρy′ + ρ′y
Chain rule: ρ′y = ρP(x)y
Therefore: (ρy)′ = ρ[y′ + P(x)y]

The integrating factor packages two terms into one derivative. Once that happens, direct integration applies.

Tutor-added memory cue
Normalize → multiply → recognize a product → integrate → divide.
ρy = ∫ρQ dx + C

Here ∫ρQ dx means one chosen antiderivative. The explicit +C represents the family of solutions.

y = ∫ρQ dx + Cρ

Dr. Casey’s page 1 writes the indefinite-integral formula without a separate +C; the worked examples display C explicitly. This studio does the same in every example.

Why only one arbitrary constant?

If both sides are integrated with constants, ρy + C₁ = F + C₂. Rearranging gives ρy = F + (C₂ − C₁). Rename the difference C.

y′ + 2xy = x

Which multiplier turns the left side into a product derivative, and what is the resulting equation?

Show a hint

Integrate the coefficient 2x. Then use (ρy)′ = ρy′ + ρ′y.

Reveal answer and correction
ρ = ex², so ρ′ = 2xex².
(ex²y)′ = xex².

If you chose e2x, you exponentiated the coefficient without first integrating it. Repair ∫2x dx = x².

dy/dx + y = 4

Classification: first-order linear. The equation is already in standard form, with P(x) = 1 and Q(x) = 4.

ρ(x) = e∫1 dx = ex

This example is also separable. We use the integrating factor to learn the method that will handle the later examples.

exy′ + exy = 4ex
(exy)′ = exy′ + exy
d/dx (exy) = 4ex

The derivative of ex is ex, so the two terms match the product rule exactly.

exy = 4ex + C
Integrate: ∫4ex dx = 4ex + C.
Divide every term by ex: y = 4 + C/ex.
y(x) = 4 + Ce−x

This is the general solution. No initial condition is supplied, so C stays arbitrary.

Common trap
The constant term becomes Ce−x after division. It does not stay +C.
y′ + y = −Ce−x + 4 + Ce−x = 4

Interval: (−∞, ∞). The coefficients and every member of this family are defined for all real x.

The equilibrium solution y = 4 appears when C = 0. We never divided by y − 4, so it was not lost.

Practice: why isn’t y = 4 + C the general solution? Reveal

A constant y = 4 + C has y′ = 0, so substitution gives 4 + C = 4. That works only for C = 0. The exponential is essential for the rest of the family.

(1 + x)y′ + y = cos(x)
y(0) = 1

Classification: first-order linear IVP. Divide every term by 1 + x, requiring x ≠ −1.

y′ + 11 + xy = cos(x)1 + x

The initial point is x₀ = 0. We work on the connected interval (−1, ∞), where 1 + x is positive.

ρ(x) = eln(1 + x) = 1 + x
In general: ∫1/(1 + x) dx = ln|1 + x| + K.
On (−1, ∞): |1 + x| = 1 + x.

This justifies the ln(1 + x) written in the notes. The interval matters when removing absolute-value bars.

What if the initial point were left of −1?

On (−∞, −1), eln|1+x| = −(1+x). Multiplying this factor by −1 gives 1+x, which also works as a nonzero integrating factor on that interval. Neither choice bridges x = −1.

d/dx [(1 + x)y] = cos(x)
Multiply the standardized equation by 1 + x:
(1 + x)y′ + y = cos(x).
The product rule gives [(1 + x)y]′ = (1 + x)y′ + y.

Multiplication returns the original left side, now recognized as one derivative.

(1 + x)y = sin(x) + C
y(x) = sin(x) + C1 + x

The entire numerator is divided by 1 + x, including C.

Why does cos(x) integrate to sin(x)?

Differentiate sin(x): its derivative is cos(x). There is no negative sign in this antiderivative.

1 = y(0) = (sin(0) + C)/(1 + 0) = C
y(x) = sin(x) + 11 + x

The initial condition selects C = 1 from the family. Its connected solution interval containing 0 is (−1, ∞).

Common trap
Substitute x = 0 into the whole solution, including its denominator.
y′ = (1 + x)cos(x) − (sin(x) + 1)(1 + x)²
(1 + x)y′ + y
= [(1 + x)cos(x) − sin(x) − 1 + sin(x) + 1]/(1 + x)
= cos(x).

Also, y(0) = (0 + 1)/(1 + 0) = 1. Both parts of the IVP check.

Can this particular solution cross x = −1?

No. Its numerator there is 1 − sin(1), which is nonzero. The solution becomes unbounded as x approaches −1 from the right. This IVP has no continuous extension through that point.

y′ + P(x)y = Q(x),   y(x₀) = y₀

Dr. Casey states that continuity of P and Q around x₀ guarantees a unique solution to the IVP.

Standard mathematical elaboration: if P and Q are continuous on an open interval I containing x₀, the linear IVP has a unique solution throughout I.

For Example 2:
P(x) = 1/(1 + x), Q(x) = cos(x)/(1 + x).
Both are continuous on I = (−1, ∞), which contains x₀ = 0.
Why does one initial value select one solution?

If two solutions have the same initial value, their difference z satisfies z′ + Pz = 0 and z(x₀) = 0. Multiplying by ρ gives (ρz)′ = 0, so ρz is constant. Its value at x₀ is 0. Since ρ never vanishes, z = 0 throughout I.

−1 < x < ∞
  1. Standardize firstIdentify P and Q after dividing by the coefficient of y′.
  2. Find the boundariesLocate coefficient discontinuities and restrictions on the solution.
  3. Keep the component containing x₀Use one connected interval, not a union separated by a forbidden point.

A theorem failing at a point means its guarantee does not apply there. It does not by itself prove that no solution or no unique solution can exist there.

P(x) = 1/(1 + x),   Q(x) = cos(x)/(1 + x)

If an initial condition were given at x₀ = −2, which maximal coefficient-continuity interval contains it?

Reveal answer and correction

(−∞, −1). The initial point lies to the left of the discontinuity. The set x ≠ −1 has two components; only one contains −2.

If you selected (−1, ∞), you reused Example 2’s initial point instead of checking the new one.

xy′ + (2x − 3)y = 4x⁴

Classification: first-order linear. There is no initial condition. The coefficient of y′ is x, so the standardized method requires x ≠ 0.

Divide every term by x. What are P(x) and Q(x)?

Show a hint

(2x − 3)/x = 2 − 3/x. Also 4x⁴/x = 4x³.

Reveal standard form
y′ + (2 − 3/x)y = 4x³

P(x) = 2 − 3/x and Q(x) = 4x³. Work on either (0, ∞) or (−∞, 0).

P(x) = 2 − 3/x

Use ∫1/x dx = ln|x|. What antiderivative belongs in the exponent?

Reveal the antiderivative and factor
∫(2 − 3/x) dx = 2x − 3 ln|x|.
ρ = e2x − 3 ln|x| = e2x|x|−3.

On x > 0 this is x−3e2x, the factor displayed in the notes.

On x < 0, Casey’s factor x−3e2x is −1 times the positive exponential factor. A nonzero constant multiple is valid, so it also works on that interval.

Source clarification: the logarithm in the notes

Page 2 writes an exponent of the form 2x − ln(x³) before simplifying to x−3e2x. That real logarithm is directly valid for x > 0. The ln|x| version above makes the negative-x interval explicit without changing the displayed working factor.

ρ = x−3e2x

Multiply the standardized equation by ρ. Simplify the right side before integrating.

Reveal the product equation
ρQ = (x−3e2x)(4x³) = 4e2x
d/dx [x−3e2xy] = 4e2x

The powers cancel because x−3x³ = 1 for x ≠ 0.

Verify ρ′ = Pρ directly
ρ′ = −3x−4e2x + 2x−3e2x
= (2 − 3/x)x−3e2x = Pρ.
(x−3e2xy)′ = 4e2x

What is ∫4e2x dx? Check the factor of 2 by differentiating.

Reveal the integrated equation
x−3e2xy = 2e2x + C

Because (2e2x)′ = 4e2x, the antiderivative is correct.

If you wrote 4e2x, its derivative would be 8e2x. Divide by the inner derivative 2 when integrating this exponential.

x−3e2xy = 2e2x + C

Multiply both sides by the reciprocal x³e−2x. What happens to each term on the right?

Reveal the general solution
y = x³e−2x(2e2x + C)
= 2x³ + Cx³e−2x.

This is Casey’s result. C is arbitrary on each connected interval. With no initial condition, we cannot choose a numerical value for C.

y = 2x³ + Cx³e−2x

Differentiate with the product rule, then substitute into the original equation.

Reveal the verification
y′ = 6x² + Ce−2x(3x² − 2x³).
xy′ = 6x³ + Ce−2x(3x³ − 2x⁴).
(2x − 3)y = 4x⁴ − 6x³ + Ce−2x(2x⁴ − 3x³).

Adding cancels 6x³ with −6x³ and cancels the entire C-dependent term. The result is 4x⁴, as required.

xy′ + (2x − 3)y = 4x⁴

Method intervals: (−∞, 0) and (0, ∞). The standardized coefficient 2 − 3/x is undefined at zero.

Original-equation check: for any fixed C, y = 2x³ + Cx³e−2x and its derivative are defined on all of ℝ. At x = 0, the equation requires −3y(0) = 0, and this family has y(0) = 0. Direct substitution therefore extends each member through zero.

Separate the two claims
The integrating-factor derivation used x ≠ 0. The extension to all real x is justified afterward by checking the original equation.
Why doesn’t uniqueness at x₀ = 0 follow?

Every value of C gives y(0) = 0, so that initial condition does not determine C. In fact, different constants may be used on x < 0 and x > 0 while joining with y(0) = 0: both one-sided derivatives tend to 0. The fixed-C formula is a global solution family, but it does not exhaust these possible joined solutions.

CthT′ = −hA(T − Ta)

Assume a component has uniform temperature, constant thermal properties, fixed ambient temperature and no internal heat source.

QuantityMeaning and units
T(t), TaComponent and ambient temperature, °C
T′(t)Temperature-change rate, °C/s
CthThermal capacitance, J/K
hAHeat-transfer conductance, W/K

A temperature difference of 1 °C equals a difference of 1 K. Both sides of the energy balance have units J/s, or W.

State versus rate

T is the current temperature. T′ says how quickly it changes. If T exceeds the ambient temperature, the right side is negative, so the component cools.

T′ + kT = kTa,   k = hA/Cth

Let Cth = 100 J/K, hA = 5 W/K, Ta = 20 °C and T(0) = 80 °C.

k = 5/100 = 0.05 s−1.
T′ + (0.05 s−1)T = 1 °C/s.

Classification: first-order linear, with t as the independent variable. The integrating factor is ρ(t) = ekt. Its exponent kt is dimensionless.

(ektT)′ = kTaekt
Integrate: ektT = Taekt + C.
Divide: T = Ta + Ce−kt.
Apply T(0) = 80 °C: C = 80 °C − 20 °C = 60 °C.
T(t) = 20 + 60e−0.05tT in °C, t in seconds

Mathematical solution interval: (−∞, ∞). Physical prediction: t ≥ 0 while the model assumptions hold.

Verification and physical meaning

T′ = −3e−0.05t °C/s. Also −k(T − Ta) = −0.05 × 60e−0.05t = −3e−0.05t °C/s, and T(0) = 80 °C. The model approaches 20 °C from above.

At t = 20 s, T = 20 + 60/e °C exactly, approximately 42.1 °C. This is one time constant, 1/k = 20 s.

y′ = 4 − y

At a point with y = 6, does the solution rise or fall as x increases?

Reveal answer and correction
y′ = 4 − 6 = −2 < 0.

The solution falls from left to right. A negative derivative describes downward direction as x increases, regardless of whether y itself is positive.

y′ = 4 − y

Where are the slope-field segments horizontal?

Reveal answer and correction
Set the entire right side to zero:
4 − y = 0 ⇒ y = 4.

This horizontal line is the equilibrium solution from Example 1. Do not set only the term −y equal to zero.

y′ + x²y = sin(x)

Is this equation linear? Identify P(x), Q(x) and an integrating factor.

Reveal answer and correction

Yes. P(x) = x² and Q(x) = sin(x). The unknown y and its derivative enter linearly.

ρ = e∫x² dx = ex³/3.

If you rejected it because of x², check the power of the unknown y instead. This is the preserved opening question extended to test the integrating factor.

2y′ + 6y = 10,   y(0) = 2

Find the exact solution and its connected interval.

Show a hint

First divide every term by 2. Then build ρ from the new coefficient of y.

Reveal full solution and check
y′ + 3y = 5; ρ = e3x.
(e3xy)′ = 5e3x.
e3xy = (5/3)e3x + C.
y = 5/3 + Ce−3x.
2 = 5/3 + C ⇒ C = 1/3.

y = 5/3 + (1/3)e−3x, on (−∞, ∞).

Check: y′ = −e−3x. Then 2y′ + 6y = −2e−3x + 10 + 2e−3x = 10, and y(0) = 2.

If ρ = e6x, the first error was reading P before standardizing.

xy′ + 2y = x²,   y(1) = 0

Find the solution and the maximal connected interval containing x₀ = 1.

Show a hint

For x > 0, standard form is y′ + (2/x)y = x. Use ρ = x².

Reveal full solution and check
(x²y)′ = x³.
x²y = x⁴/4 + C.
y = x²/4 + C/x².
0 = 1/4 + C ⇒ C = −1/4.

y = x²/4 − 1/(4x²), on (0, ∞).

y′ = x/2 + 1/(2x³), so xy′ + 2y = x²/2 + 1/(2x²) + x²/2 − 1/(2x²) = x². Also y(1) = 0.

The solution blows up at 0. It cannot be extended through zero, and the negative-x interval does not contain the initial point.

y′ + 2y = x

A proposed step is (e2xy)′ = x. Identify the first error and repair that line.

Reveal correction
Correct: (e2xy)′ = xe2x.

The integrating factor is correct. The first error is failing to multiply the right side by e2x. Distribute the multiplier across the entire equation.

xy′ + (2x − 3)y = 4x⁴,   y(0) = 0

Does the linear uniqueness theorem guarantee a unique solution at x₀ = 0? What does Example 3 actually show?

Reveal answer and correction

No. Standardization produces P = 2 − 3/x, which is undefined at 0, so the theorem does not apply there.

Direct substitution shows that every fixed-C function y = 2x³ + Cx³e−2x solves the original equation for all real x and satisfies y(0) = 0. These are distinct solutions, so this particular IVP is nonunique.

The theorem’s failed hypothesis alone would not establish nonuniqueness. The explicit distinct solutions do.
