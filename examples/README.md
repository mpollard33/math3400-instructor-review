# Homework-helper example

[Open the supplied screenshot](homework-helper.png).

The image illustrates a complementary workflow for an active homework problem:

1. Identify the equation’s structure and compare candidate methods.
2. Give feedback on the classification with a reason.
3. Show the consequential algebraic transformation.
4. Keep a concise method reference available beside the conversation.
5. Continue through the problem while distinguishing overlapping methods when relevant.

The example compares separable, linear and Bernoulli forms. It shows that one equation
can satisfy more than one method’s diagnostic form and explains the natural choice for
the displayed problem. It is an example of guided assistance, not an exhaustive list of methods.

identifiers; its PNG metadata is empty. The ZIP does not include the underlying homework
chat, a conversation export or a runnable chat service.
