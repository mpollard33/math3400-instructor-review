## Package checks

The following are checked when finalizing this ZIP:

1. Exactly six selected lesson exports, with no alternate lesson drafts.
2. Byte identity between the selected exports and packaged lesson files.
3. Byte identity of the supplied screenshot, visual privacy inspection and PNG metadata inspection.
4. Known personal/private-identifier scan, allowing only the requested project credit.
5. Inline JavaScript syntax and embedded JSON parsing.
6. Local HTML/image links, file inventory and SHA-256 integrity.
7. ZIP extraction integrity and neutral archive metadata.

Browser rendering and live click behavior are not newly verified in this packaging pass:
the available browser automation package has no installed browser executable. Syntax and
link checks do not establish visual layout, accessibility or lesson efficacy.
